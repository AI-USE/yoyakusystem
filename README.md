# メイドカフェ予約システム

このリポジトリには、メイドカフェ向けの予約システム（利用者用 LIFF 画面および管理者用ダッシュボード）が含まれています。

## 構成
- **liff/**: 利用者が LINE 内で開く予約画面（完全な静的 HTML/JS 構成。Cloudflare Pages 等に最適）
- **admin/**: スタッフが使用する管理画面（Next.js 15 動的サーバー。Render 等に最適）
- **supabase/**: データベース設計（SQL スキーマ）

## 特徴
- **利用者 (LIFF)**: 
  - ビルド不要の静的ファイル構成で、アクセスが集中しても安定して動作します。
  - モダンで「かわいい」メイドカフェ風デザイン。
  - 突発的な「怖い」グリッチ演出を搭載。
  - **識別子付きQR**: 予約希望枠をエンコードしたQRを発行し、受付の手間を最小化。
- **管理者 (Admin)**: 
  - **権限分離ログイン**: `Admin`（全操作可能）と `Staff`（受付・枠管理のみ）の2段階パスワード。
  - **スマート受付スキャン**: カメラによるQRスキャン、または名簿からの手動入場処理。
  - **モバイル最適化**: 現場スタッフがスマホ1台で全ての操作（受付・名簿確認・BAN）を行えるUI。
  - **運行管理**: 公演スケジュールの「一括スライド」や、特定枠の緊急中止機能。
  - **自動ステータス管理**: 公演時間が終了すると、画面上のステータスが自動的に「体験終了」へ遷移。
  - **防衛機能**: 悪質ユーザーの即時BAN（ブラックリスト登録）および自動予約拒否。
